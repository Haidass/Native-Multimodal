当前初筛覆盖

分布统计

分辨率、短边、长边、像素数、比例和质量分布；全量直方图与抽样分位数。

分辨率与八桶筛选

短边下限、精确宽高、严格比例和默认 5% 可调宽松偏差。

规范化与文本规则

EXIF、ICC、RGB、透明背景、Unicode、文本长度与正则检查。

技术质量代理

模糊、噪声、信噪比与块效应指标；阈值需针对你的数据校准。

全局去重

文件和像素精确去重，pHash / dHash / RMSE 联合近重复复核。

多进程与多机

SQLite 检查点与静态 rank；汇总分片后统一筛选、去重和报告。

看报告时，先核对这些数字

输入总数 = 保留 + 拒绝 + 重复 + 错误。比较分辨率独立通过率、桶独立通过率、最终保留率，以及各桶筛选前后数量。初筛结果仍需人工抽查图文对应关系与质量。
